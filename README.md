# Bayan | بيان

**Bayan (بيان)** is a bilingual Natural Language Processing (NLP) project designed to process and analyze Arabic and English text.

The project focuses on building an end-to-end NLP system for understanding and processing bilingual textual data using modern Natural Language Processing and Transformer-based techniques.

Bayan was implemented as part of the **Natural Language Processing with Transformers** training course provided by **SDAIA Academy**.

SDAIA Academy GitHub: https://github.com/SDAIAAcademy
